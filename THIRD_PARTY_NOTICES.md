# Third-party notices

FundVal v14 bundles the following static assets only after a user explicitly starts local screenshot OCR. They are not loaded during normal application startup.

| Component | Pinned version | Shipped asset use | License |
| --- | ---: | --- | --- |
| `@paddleocr/paddleocr-js` | 0.4.2 | Primary browser-side text detection and recognition SDK | Apache-2.0 |
| PP-OCRv6 tiny detection / recognition models | v6 tiny, hash-pinned | Local Simplified-Chinese detection and recognition | Apache-2.0 |
| `onnxruntime-web` | 1.27.0 | Local single-thread WebAssembly inference runtime | MIT |
| `@techstark/opencv-js` | 4.10.0-release.1 | Image preparation used by PaddleOCR JS | Apache-2.0 |
| `js-yaml` | 4.3.1 | Paddle model metadata parser | MIT |
| `clipper-lib` | 6.4.2 | Paddle text-box polygon processing | Boost Software License 1.0 |
| `tesseract.js` | 7.0.0 | Browser-side OCR API and Worker | Apache-2.0 |
| `tesseract.js-core` | 7.0.0 | LSTM WebAssembly OCR core | Apache-2.0 |
| `@tesseract.js-data/chi_sim` | 1.0.0 | Simplified-Chinese trained data (`4.0.0_best_int`) | MIT |

PaddleOCR JS with PP-OCRv6 tiny is the production long-screenshot engine. Tesseract remains a local fallback module and regression reference; neither engine is loaded by the FundVal home page. The deployed artifact includes license copies under `assets/ocr/licenses/`. Model files are accepted only when their byte length and SHA-256 match the build manifest.
